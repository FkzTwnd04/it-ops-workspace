# 账号锁定与密码重置

## 适用场景
- 提示"账号已被锁定"、"密码已过期"、"用户名或密码错误"
- 用户忘记密码

## 标准流程
1. 用 get_user_account 查询账号状态，确认是锁定、过期还是两者都有。
2. 仅锁定、密码未过期：执行 unlock_account（低风险），并提醒用户检查手机、平板上是否保存了旧密码，
   旧密码反复重试是锁定的最常见原因。
3. 密码已过期或用户忘记密码：执行 reset_password（高危，需审批），临时密码通过短信发给本人，
   用户首次登录必须修改。
4. 近 24 小时登录失败次数超过 20 次且来源不明：不要解锁，转人工安全排查。

## 给用户的说明
- 新密码至少 12 位，包含大小写字母和数字，不能与最近 5 次相同。
- 修改后在所有设备（邮箱客户端、VPN、手机）上更新密码。
